## 原始检索对照

固定6 PDF、63物理页、282 chunks、24题：21题可回答，3题缺证（Q04/Q20/Q24）。开发Agent在运行前选定原句并绑定页/字符区间；跨块原句的所有相关片段计入标签。非穷举相关性、非独立双人金标准；这些题现已用于多轮开发，不能作为未见确认集。

- 单题Recall@10 = 前10名命中的已标注相关片段数 / 本题已标注相关片段数。逐题计算后对21题宏平均；不是“命中一条就算1”的Hit@10。
- MRR@24 = 首个相关片段排名倒数，对21题取均值；前24条无命中为0。
- 缺证3题仍执行/留档，不计质量均值、不记满分。结果为空或分数低不能证明客观无答案。
- 原始耗时覆盖全部24题，每题单次热运行；共享通道的实测组件用时求和。不是独立端到端回答时间，不含DeepSeek生成。
- P95取排序后第ceil(0.95×n)项（nearest-rank）；单次热测分位数不是生产SLA。

| 路线 | Recall@10，21题 | MRR@24，21题 | 热组件中位数，24题 | P95，24题 |
|---|---:|---:|---:|---:|
| BM25 | 66.67% | 0.3127 | 1.22 ms | 1.75 ms |
| 向量 | 76.19% | 0.3052 | 42.98 ms | 70.44 ms |
| RRF | 85.71% | 0.4167 | 43.97 ms | 72.04 ms |
| RRF＋Cross-encoder | 90.48% | 0.3767 | 1938.22 ms | 2139.77 ms |

从逐题排名、标签和seconds重算一致。BM25→最终路线Recall增加23.81个百分点；RRF→重排只增加4.76个百分点，MRR下降0.0400且更慢。**没有得到Recall、MRR、时延均衡改善的默认配置证据。** 默认仍为RRF＋纯CE、24候选、batch4/2线程，本轮未改。

本机ONNX模型：`intfloat/multilingual-e5-small`（384维）与`cross-encoder/mmarco-mMiniLMv2-L12-H384-v1`。原环境Apple M2/8GB；模型权重/tokenizer/revision、切分配置、原文版本已冻结。冷初始化/建库成本单列于原result/corpus；表中不含Qdrant服务RSS，也不代表并发性能。
