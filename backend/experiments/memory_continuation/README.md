# 接续摘要与结论更正实验

本分支基于 ReleaseV1.5 的 `866c193`，在独立 worktree 中尝试模型生成的研究接续摘要和显式更正关系。

## 范围

- 仅显式构造 `TaskExecutor(..., continuation_memory=True)` 的新会话根任务启用；默认结束参数与运行入口保持原合同；本分支另明确常规规划中的逐字引句与零论文对话类型说明，不改变材料、来源或权限校验。
- Supervisor 在既有 `finish_task` 响应中提供结构化接续候选，复用原模型收据、共享预算和恢复机制。不是额外的后台模型请求。
- 程序独立校验来源、历史可见范围、旧结论 hash 和时间顺序；以版本化历史索引保存，不升级论文核验状态或继承保存权限。
- 摘要无效或缺失时，保留回答和原始历史，记录旁路结果。恢复只补数据库投影，不重发模型。
- 第一版覆盖任务结束后的接续；任务中途按容量触发的独立模型压缩另行设计。

## 隔离与验证

测试使用临时 SQLite、临时文件、合成对话和模型替身；测试环境拒绝外网连接，不读取部署凭据，不连接部署数据库。该离线入口不调用真实模型；真实验证另见 [REAL_VALIDATION.md](REAL_VALIDATION.md)，须先冻结授权、材料和预算。离线通过只证明工程行为，不表示摘要语义质量已经实测。

在独立 checkout 中按已有锁文件建立虚拟环境后，从仓库根运行：

```sh
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -B backend/experiments/memory_continuation/run_offline.py --output artifacts/memory-continuation-review
```

输出目录须尚不存在。入口移除服务相关环境变量、拒绝网络及非临时SQLite，只运行接续实验和相关回归，并保存 `tests.json`、`tests.log` 与 `synthetic-demo.json`。演示包含原结论、显式更正和下一轮接续目录；所有回答和用量均来自替身，不能作为真实模型质量或计费证据。

摘要状态分为 `applied`、`rejected`、`not_proposed`。结论和更正保留来源身份、hash及未核验状态；同批新读取不算模型已见，撤销偏好会保守卸载直接和间接依赖它的摘要。目录容量不足时卸载完整摘要，原始记录继续可读。
