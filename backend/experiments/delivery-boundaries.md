# 正常交付路径与实验来源说明

本轮先验证正常使用路径，再决定是否修改业务代码。普通论文检索仍经过
DiscoveryProvider 的来源 RPC、候选标准化、PaperService 授权、Researcher
交接和 Supervisor 收尾。测试只替换外部 HTTP、生成模型和 PDF 解析边界。

## 当前结论

- 普通检索的选中 paper_id、题名和链接可以交回父角色；父角色可读取同一论文。
- 已提交阶段发现后遇到传输中断，任务保留阶段内容及独立 gaps，状态为 partial。
- 只有已读页、尚无研究发现时，任务保留材料定位并报告失败；不能将其改判为可用回答。
- 未知请求恢复不自动重发，缺失 usage 保持未知。替身用量不是真实模型指标。
- 未据此修改业务交接、错误恢复、角色提示词、Memory 或 Reflection 机制。

本次新增九项实际 API/Worker 路径检查，以及八项实验来源说明检查；与原十项
输入前置检查合计二十七项。部署等价 A 与联合提示词 B 分别运行，两个变体均通过。
这些是离线工程证据，不代表真实模型未来必然采用正确工具或给出正确科学结论。

## 唯一行为变更

`scripts/prompt_bundle_cases.py` 在实验安装本地题录替身时，为实际注册的
search_papers schema 增加本轮来源能力说明：实际池大小、来源标签、过滤含义、
单次上限、题录依据层级，以及存在时的材料编号位置。数量和来源取自已验证输入。

只在实验 ExitStack 内生效；退出恢复，嵌套安装不积累旧池说明。无候选池和被隐藏
工具不增加说明。参数模型、handler、权限、排序、日期处理与角色提示词均保持。
来源说明不含论文正文、评分答案或推荐名单。两实验变体使用同一修改。

正常产品不加载该安装器，因此不新增固定论文池功能。测试材料编号不是产品身份
合同；没有正常路径的缺陷证据时，不为实验编号增加业务映射。
