# RAG 检索路线实验

本目录说明独立组件实验。实验入口不接入 API、Worker 或默认检索配置；代码在独立 Git 分支审阅，通过后再讨论产品接入。

## 比较问题

在同一授权文件语料、原问题、非穷尽相关性标签和同版本地重排器下，比较：

| 路线 | 候选选择 | 最终排序 |
|---|---|---|
| `bm25_rerank` | 原问题、原文 BM25，最多24条 | 原问题与原片段的 Cross-encoder 分数 |
| `located_bm25_rerank` | 显式论文名定位、通用中英概念扩展、已有章节字段；18个论文内槽与6个全库BM25保底槽 | 同一重排器、相同输入容量和候选上限 |

论文别名只能由输入语料的公开标题按通用规则派生。歧义不硬筛；跨篇明确名称保留各篇候选。候选路由不改变授权范围，片段正文、来源身份和引用偏移保持。章节缺失不自动补造。概念词典独立于评测题目与答案，结果出现后不调整词典或配额追分。

两路重排均保持 CPU、2线程、batch4、原输入顺序、512 token上限与超长整批拒绝。候选增强文字不送入重排器。没有新Embedding、LLM查询改写、生成答案或外部API调用。

## 输入与边界

执行者显式提供本机语料、目录、问题、标签与模型清单。检索器只能接收query、授权范围和语料catalog，评分器独立读取标签；答案paper_id、keypoints、gold不能参与材料路由。所有输入先冻结SHA-256，重复片段ID、来源身份/hash/偏移不一致及越权立即停止。

运行器拒绝网络、SQL和业务进程启动，只向预先新建的独立结果目录追加文件。模型权重和依赖复用既有本地只读资产，无自动下载或安装；不加载业务Settings或.env。结果目录不得复用，不覆盖失败记录。

## 评价合同

- 固定首热轮计算质量；每题每路线3次热运行用于时延与稳定性。串行执行并轮换路线先后，2次初始化单列，不冒称独立冷启动分布。
- 报已标正例Recall@5/@8/@10、MRR@24、候选覆盖@24，以及缺证题、空结果、失败和降级。非穷尽标签不等同答案正确率，历史暴露题不冒充独立测试。
- 两路同批计时包括每题scope选择、词法候选选择和重排；输入文件/hash核验、一次性词项准备及结果写盘在计时外并单列。不能将该纯文件组件时间与历史SQL/Qdrant装配耗时直接相减称提速。
- 同时保留重排前指标，辨别候选覆盖与后续排序的变化。局部候选按论文重新计算IDF是B路线的一部分；组合路线收益不能归因于其中单个改动。
- 两路线共享24上限，但候选同伴改变可能影响INT8动态量化分数；本实验测完整路线，不充当量化因果对照。
- 上限为114题×2路线×3热重复，加每路线1次初始化：最多686次本地评分尝试、16,464个query-passage评分对；正常空候选可减少实际次数。超过60分钟或发生输入/隔离/资源边界错误停止并保留未执行计划格，不重跑筛选成绩。

## Git与回退

开发在独立worktree与实验分支进行。保留基础提交、实验前计划提交与实现提交，并把经过公开检查的源代码、合成测试和本说明备份至GitHub分支。私有材料、标签、原始记录、权重、环境配置及本机开发文档留在本机。

审阅时用`git diff <base>..<candidate>`查看范围。需要撤销已共享提交时，在实验分支用`git revert <candidate>`形成新的撤销提交；不强推、不对部署目录执行reset。采用实验结果、合并main或部署属于后续决定。

## 方法参考

- [Hybrid Fusion分析](https://arxiv.org/abs/2210.11934)：融合规则应通过本任务对照验证。
- [Contextual Retrieval](https://www.anthropic.com/research/contextual-retrieval)：关注片段缺少上下文的问题；本实验仅使用已有元数据与固定术语，不冒称复现LLM生成上下文。
- [Late Chunking](https://arxiv.org/abs/2409.04701)、[ColBERTv2](https://arxiv.org/abs/2112.01488)：作为后续候选，本轮不替换编码器或重建多向量索引。
