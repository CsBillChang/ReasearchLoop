# H1 同题真实对照的隔离执行层

该实验层比较冻结基线与 H1 finding_id 参数说明候选。每版加载各自业务源码，共用实验资源、HTTP 预算门和评分口径，不修改业务缓存、权限、上下文或检索算法。

`harness_ab_resources.py` 复制已验证的同版 PDF 解析缓存与文档向量，在专属 Qdrant/SQLite 安装索引；索引存在不构成读取授权，只有本格正常上传、读取后的证据可用于检索。查询与重排仍使用原生实现。来源文件、模型和依赖均由私有 manifest 明确指定，不下载模型或重算文档向量。

`harness_ab_budget.py` 使用独立 SQLite 原子预留全批与根任务族额度。`harness_ab_transport.py` 在实际 HTTP 边界要求官方端点、冻结参数、文本输入及显式输出上限；支持普通 JSON 与 SSE。完整用量才结算，未知结果保持预留并冻结批次，没有自动重试。Token 按实际输入加输出计算，缓存及推理明细不重复叠加；人民币估价不是供应商账单。

SSE 先经 HTTPX 公开解码 API 处理压缩，再识别事件和用量，归档明确保存解码字节。结束标记须等压缩流完整性检查完成后才交给原生适配器；外层移除编码和长度头，避免重复解压。gzip、deflate、zstd 的完整、缺用量、截断及提前关闭场景分别验证，不能把原始压缩字节当作 SSE 正文解析。

`run_harness_ab.py` 每次仅运行一个已冻结格。它显式隔离配置、SQLite、缓存/输出/临时根、会话和上传，禁止默认 .env、日常数据库/向量服务及未批准网络；所有角色通过共同传输记账。每格先创建新的空会话，以正常 Memory 与 Supervisor 流式路径运行。资格模式不构造生成模型；真实模式还要求非空源码/材料冻结、GitHub 回退提交、资格收据和独立授权，凭据只从父进程内存管道注入。

示例资格调用，输出路径和来源均由私有 manifest 决定：

```sh
python -B backend/scripts/run_harness_ab.py --manifest /absolute/private/manifest.json --case H1-Q1 --variant A --mode qualify
```

独立父驱动须验证固定矩阵的每格只执行一次，并为每个子进程设置根任务与整批剩余时间的绝对截止。HTTP 的空闲读超时不能代替绝对墙钟。触及截止时保留在途预留、停止全批，不重发；清理进程和封存记录属于执行后的收尾。

授权新批次扣除历史消耗时，父驱动和单格入口均采用同一份 manifest.ledger_limits。金额按 Decimal 精确转换为整数纳元；历史实际用量、历史保守预留与新额度分别记账，旧失败账本保持。新批次与历史合计不得越过累计上限。

输出包含持久事件、任务视图、根/子任务行动、原始响应、模型收据及预算账本。端到端时延由根 task_created/task_finished 计算；未结束任务单列观察时间。全矩阵保留 failed/partial/unknown/未创建和所有费用，不只比较成功样本。实际运行数量及成绩只以私有结果为准，合成测试和资格不代表真实效率收益。

实验代码单独提交，保留 H1 候选与其父基线，采用与否不自动切换部署。共享代码撤销使用 revert；Git 不恢复数据库。PDF、模型、凭据、真实轨迹及本机评测文件不上传。
